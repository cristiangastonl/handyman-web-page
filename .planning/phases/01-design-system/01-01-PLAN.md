2. **AdminCssInjector component (internal, not exported):**
   A component that injects the `adminCss` string as a `<style>` tag. Use a ref or useEffect to avoid duplicate injection. Simplest approach: render `<style dangerouslySetInnerHTML={{ __html: adminCss }} />` inside AdminButton or AdminInput. Better approach: export a single `AdminStyles` component that renders the `<style>` tag, and document that it should be rendered once in AdminPanel. Simplest of all: just render the style tag inline at module level via a self-invoking pattern. Use the simplest approach that works: export an `AdminStyles` component that renders `<style>{adminCss}</style>`.

3. **AdminButton component (`export function AdminButton`):**
   - Props: `children`, `variant = "primary"` (one of "primary", "secondary", "danger"), `size = "standard"` (one of "standard", "small"), `loading = false`, `disabled = false`, `style`, `...props`
   - Compute `isDisabled = loading || disabled`
   - Select base style: `variant === "danger" ? A.btnDanger : variant === "secondary" ? A.btnSecondary : A.btnPrimary`
   - Select size override: `size === "small" ? A.btnSmall : {}`
   - Compute className: `"admin-btn" + (variant === "primary" ? " admin-btn-primary" : variant === "danger" ? " admin-btn-danger" : " admin-btn-secondary")`
   - Render `<button>` with className, disabled={isDisabled}, merged style (base + size + opacity 0.5 if disabled, cursor not-allowed if disabled + style prop override)
   - If `loading` is true, render a small spinner span (8px wide, 8px tall, border: 2px solid currentColor, borderTopColor: transparent, borderRadius: 999, display: inline-block, animation: "spin 0.6s linear infinite") before children text. The @keyframes spin already exists in the global CSS.
   - Render children text (or "Saving..." if loading and no children override desired -- actually just show spinner + children so button text stays visible)

4. **AdminInput component (`export function AdminInput`):**
   - Props: `label`, `type = "text"`, `style`, `...props`
   - Render wrapping `<div>` with marginBottom: spacing.lg
   - If label, render `<label style={A.inputLabel}>{label}</label>`
   - Render `<input type={type} className="admin-input" style={{...A.input, ...style}} {...props} />`

5. **AdminTextarea component (`export function AdminTextarea`):**
   - Props: `label`, `style`, `...props`
   - Render wrapping `<div>` with marginBottom: spacing.lg
   - If label, render `<label style={A.inputLabel}>{label}</label>`
   - Render `<textarea className="admin-input" style={{...A.textarea, ...style}} {...props} />`

6. **AdminCard component (`export function AdminCard`):**
   - Props: `title`, `children`, `style`, `...props`
   - Render `<div style={{...A.card, ...style}} {...props}>`
   - If title, render `<div style={A.cardTitle}>{title}</div>`
   - Render `{children}`

7. **AdminLabel component (`export function AdminLabel`):**
   - Props: `children`, `style`
   - Render `<div style={{...A.inputLabel, ...style}}>{children}</div>`

8. **AdminStyles component (`export function AdminStyles`):**
   - No props
   - Render `<style>{adminCss}</style>`
   - Document in a comment: "Render once in AdminPanel to inject admin-specific CSS for focus/hover states"

All components are thin wrappers. No useState, no useEffect (except possibly for style injection), no complex logic. They apply tokens from adminStyles.js and forward props.
