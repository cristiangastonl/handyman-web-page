For each component, import `getStyleConfig` from constants.js and apply the style values. Every component uses inline styles (project convention). The pattern is:

```javascript
const style = getStyleConfig(siteConfig, "the_key");
// Then in JSX:
style={{ fontSize: style.fontSize, fontFamily: `'${style.fontFamily}', sans-serif`, ...otherExistingStyles }}
```

**IMPORTANT:** When adding `fontFamily`, always append `, sans-serif` as fallback. When adding `fontSize`, use `style.fontSize` as a number (React handles px automatically for numeric values in style objects).
